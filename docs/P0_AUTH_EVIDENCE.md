## 已通过的端到端行为

- 匿名请求客户 Dashboard API 返回 `401`。
- 匿名访问 `/dashboard` 返回 `307` 并跳转到 `/login?returnTo=/dashboard`。
- 管理端成功创建客户组织、正式项目、主品牌和一次性邀请。
- 客户接受邀请后自动建立用户、组织成员和安全会话。
- 接受邀请的客户无需复制数据，立即读取管理端创建的同一项目。
- 正式新项目回答数为 `0`，没有自动生成演示数据或虚假趋势。
- 已使用的邀请再次提交返回 `410`。
- 重新生成邀请后，旧链接返回 `410`，新链接返回 `200`。
- 退出后原会话请求客户 API 返回 `401`。
- 错误密码返回 `401`，正确密码返回 `200`。
- A 组织客户请求 B 组织项目时，项目列表仍只包含 A 组织项目。
- A 组织客户修改 B 组织项目时返回 `404`。
- 只读访客读取本组织项目成功，新增提示词返回 `403`。
- Collector 接口缺少密钥或使用错误密钥时返回 `401`；正确密钥在无任务时返回 `204`。
- 自动化运行时测试会从全新数据库启动前台与管理端，创建 A/B 两个组织，验证篡改项目 ID 不能跨组织读取或修改，并在退出后验证原会话立即失效。
- 客户后台趋势只按真实回答日期聚合；少于两个真实采集日时显示明确空状态，不生成模拟折线。
- 空知识库不再显示示例品牌、示例网址、虚构文件大小或固定更新时间。
