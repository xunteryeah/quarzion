# GEO Proof 指标字典

## 统计范围

有效回答指运行状态为 `parsed` 且存在非空回答正文的样本。失败、超时、被阻止和解析失败的运行不进入品牌表现分母，但必须进入运行完成率分母。

## 核心指标

### 运行完成率

`解析成功运行数 / 计划运行总数`

### 品牌提及率

`提到主品牌的有效回答数 / 有效回答总数`

品牌词提示和非品牌词提示必须分别计算。

### 第一名率

`主品牌位置为 1 的有效回答数 / 有效回答总数`

### 前三名率

`主品牌位置不大于 3 的有效回答数 / 有效回答总数`

### 平均排名

只在主品牌被提及的回答中计算位置算术平均值。未提及样本不进入平均排名，但仍进入提及率分母。

### 平均情绪

只在主品牌被提及且具有有效情绪分的回答中计算。范围为 0–100。

### SOR

单条回答中：`主品牌提及次数 / 所有已识别品牌提及次数`。项目 SOR 是有效回答的平均值。

### 域名覆盖率

`引用该域名的有效回答数 / 有效回答总数`

同一回答重复引用同一域名时只计一次覆盖。

### 主品牌关联率

`同时包含该域名引用和主品牌的回答数 / 包含该域名引用的回答数`

### 引用覆盖率

`已经被 AI 引用的已发布 URL 数 / 已发布 URL 总数`

## 效果证明

- 前后窗口必须使用相同的平台和提示词集合。
- 需要展示每个窗口的有效回答数与运行完成率。
- 品牌词与非品牌词分开比较。
- 提及率变化为 `发布后提及率 - 发布前提及率`。
- 平均排名仅在各自窗口被提及的样本中计算。
- 若没有对照提示词或样本量不足，只能描述为相关变化，不声明因果。
