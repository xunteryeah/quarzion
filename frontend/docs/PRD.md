# GEO Proof 产品需求文档

## 1. 产品目标

GEO Proof 是一套供服务团队内部使用的多客户 GEO 监测与效果证明系统。它把提示词监测、AI 回答留存、品牌与引用解析、优化任务以及发布后的前后变化串成一条可审计链路。

首版覆盖三个阶段：

- 第 0 阶段：方法论、指标、架构和验收标准。
- 第 1 阶段：客户项目、提示词、运行、原始回答、解析和基础报表。
- 第 2 阶段：引用分析、实体复核、优化任务和效果证明。

## 2. 核心用户

- GEO 策略负责人：定义提示词、分析差距、制定优化方案。
- 项目经理：管理客户、任务、负责人和交付节奏。
- 数据分析师：检查运行质量、实体准确率和指标口径。
- 客户负责人：查看结果、证据和发布后的变化。

## 3. 核心业务流程

1. 创建客户项目、主品牌、竞品和品牌别名。
2. 按主题维护品牌词与非品牌词提示词，选择目标平台。
3. 调度器生成 `提示词 × 平台 × 日期 × 采样序号` 的唯一运行任务。
4. 平台适配器保存原始回答、引用、运行状态和错误。
5. 解析器提取品牌、排名、情绪和引用，并保留解析版本。
6. 报表按平台、提示词、品牌和来源展示可复核指标。
7. 人工复核新别名、重复品牌、产品系列和型号。
8. 将分析结论转成优化任务，记录发布 URL 和完成时间。
9. 使用相同提示词和平台对比发布前后窗口，输出证据包。

## 4. 首版页面

- 总览：核心指标、趋势、平台表现、重点机会。
- 提示词：主题、品牌词标记、平台、回答数和提及率。
- 运行中心：排队、采集、解析、失败、重试和原始回答。
- 回答证据：完整回答、品牌位置、情绪和引用。
- 引用情报：域名、来源类型、覆盖率、主品牌关联率。
- 实体复核：待确认别名、归属建议、历史回算状态。
- 优化任务：任务、负责人、平台、提示词、发布 URL。
- 效果证明：发布前后指标、首次引用时间和原始证据。

## 5. 首版边界

首版以内部使用、简体中文、中国地区为默认场景。平台采集器采用可替换接口，演示环境使用结构化种子数据模拟 DeepSeek、豆包和元宝的完整运行链路。实际平台凭据和合规采集方式在生产接入时配置。

暂不优先建设：自动媒体发布、复杂计费、全自动写作、不可解释综合分、十几个平台同时接入。

## 6. 成功标准

- 所有报表数字可以回溯到原始回答。
- 所有比例能够展示分子和分母。
- 运行唯一键杜绝重复入库。
- 人工修正实体后保留审计记录。
- 优化任务能够关联目标提示词、平台和发布 URL。
- 效果证明使用匹配的前后窗口与相同监测集合。
