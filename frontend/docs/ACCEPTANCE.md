# GEO Proof 验收标准

## 数据质量

- 相同运行唯一键不会生成重复记录。
- 总览、平台、提示词、来源和回答页面可以完整对账。
- 所有指标能追溯到有效回答和运行状态。
- 运行失败原因、重试次数和解析版本可见。
- 历史实体纠错有审计记录。

## 产品功能

- 可以切换项目并查看项目数据。
- 可以查看提示词、平台、运行、回答和引用来源。
- 可以审批或驳回待复核品牌别名。
- 可以对失败运行发起重试。
- 可以创建优化任务并更新状态、发布 URL 和完成时间。
- 可以查看任务对应的基线、发布后结果和原始证据。

## 首版目标

- 运行完成率展示正确，内部目标为至少 95%。
- 品牌实体人工抽查准确率目标为至少 95%。
- 重复样本为 0。
- 关键指标对账差异为 0。
- 所有完成任务都能保存发布 URL 或明确标记无发布物。
